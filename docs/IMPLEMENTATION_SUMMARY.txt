ENVIRONMENT VARIABLES REQUIRED
══════════════════════════════════════════════════════════════════════════════

Critical (must be set):
  NODE_ENV                    development/production/testing
  MONGODB_URI                 MongoDB connection string
  JWT_SECRET                  >= 32 characters (base64 recommended)
  JWT_REFRESH_SECRET          >= 32 characters (base64 recommended)

Optional but Recommended:
  SMTP_HOST                   Email configuration
  CLOUDINARY_CLOUD_NAME       File upload storage

Tuning:
  RATE_LIMIT_WINDOW_MS        900000 (15 minutes)
  RATE_LIMIT_MAX_REQUESTS     100 (per window)
  ENABLE_HELMET               true
  LOG_LEVEL                   info (error/warn/info/debug)

All variables now validated at startup. Invalid config prevents server boot.

ARCHITECTURE IMPROVEMENTS
══════════════════════════════════════════════════════════════════════════════

Before:
  Controllers ─→ Random permission checks ─→ Maintenance nightmare

After:
  Controllers ─→ EntitlementsService ─→ Centralized logic ─→ Easy to change

Result: Policy changes take minutes instead of hours. Subscription upgrades
are consistent across the entire platform.
